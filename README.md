# Meeting Room Booking API
Небольшой REST API на Django + DRF для бронирования переговорных комнат.  
Проект демонстрирует понимание архитектуры Django, валидации бизнес-логики, безопасной конфигурации и контейнеризации.
## 🔧 Основные возможности
- Просмотр списка переговорных комнат с описанием и оборудованием
- Бронирование комнаты на заданный временной интервал
- Защита от пересечения бронирований в одной комнате
- Только авторизованные пользователи могут создавать/удалять бронирования
- Валидация временных границ (нельзя забронировать прошлое)
## 🛠 Технологии
- **Backend**: Django 5.2 + Django REST Framework
- **База данных**: PostgreSQL (в продакшене), SQLite (для локальной разработки)
- **Контейнеризация**: Docker + Docker Compose
- **Безопасность**: 
  - Секреты вынесены в `.env`
  - `python-decouple` для управления конфигурацией
  - `ALLOWED_HOSTS`, `CSRF`, `SessionAuthentication`
- **Тестирование**: валидация через DRF-сериализаторы
## 🚀 Запуск локально
1. Клонируй репозиторий
2. Создай виртуальное окружение и установи зависимости:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Linux/macOS
   venv\Scripts\activate     # Windows
   pip install -r backend/requirements.txt
   ```
3. Настрой `.env` (используй `.env.example` как шаблон)
4. Примени миграции и создай суперпользователя:
   ```bash
   python manage.py migrate
   python manage.py createsuperuser
   ```
5. Запусти сервер:
   ```bash
   python manage.py runserver
   ```
6. API доступно по:  
   - `/api/rooms/` — список комнат  
   - `/api/bookings/` — управление бронированиями

## 🐳 Запуск в Docker
1. Убедись, что Docker и Docker Compose установлены
2. В корне проекта (рядом с `Dockerfile`) создай `.env` на основе `.env.example` (также скопируй `.env` в папку `backend`)
3. Собери и запусти:
   ```bash
   docker compose up --build
   ```
4. В новом терминале накати миграции:
   ```bash
   docker compose exec web python manage.py migrate
   ```
