# Meeting Room Booking API

Небольшой REST API на Django + DRF для бронирования переговорных комнат.  
Проект демонстрирует понимание архитектуры Django, валидации бизнес-логики, безопасной конфигурации и контейнеризации.

## 🔧 Основные возможности

- Просмотр списка переговорных комнат с описанием и оборудованием
- Бронирование комнаты на заданный временной интервал
- Защита от пересечения бронирований в одной комнате
- Только авторизованные пользователи могут создавать/удалять бронирования
- Валидация временных границ (нельзя забронировать прошлое)

## 🛠 Технологии

- **Backend**: Django 5.2 + Django REST Framework
- **База данных**: PostgreSQL (в продакшене), SQLite (для локальной разработки)
- **Контейнеризация**: Docker + Docker Compose
- **Безопасность**: 
  - Секреты вынесены в `.env`
  - `python-decouple` для управления конфигурацией
  - `ALLOWED_HOSTS`, `CSRF`, `SessionAuthentication`
- **Тестирование**: валидация через DRF-сериализаторы
